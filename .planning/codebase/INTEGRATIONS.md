## APIs & External Services

**Google Cloud Vision API:**
- Purpose: AI-powered food ingredient detection from camera/gallery images
- Endpoint: `https://vision.googleapis.com/v1/images:annotate` (`lib/services/firebase_service.dart` line 116)
- Feature used: `LABEL_DETECTION` with `maxResults: 20` (line 184)
- Auth: API key passed as query parameter `?key=<VISION_API_KEY>`
- SDK/Client: `dio` HTTP client with 30s receive timeout (line 190)
- Post-processing: Food-only allowlist filter at >= 65% confidence (`_foodKeywords` set, lines 120-159; `_minVisionConfidence = 0.65`, line 34)
- Returns: `List<DetectedIngredient>` sorted by confidence descending
- Error handling: Surfaces Google's error messages from 4xx responses and in-response error objects (lines 201-217)
- Env var: `VISION_API_KEY` via `String.fromEnvironment()` compile-time constant (line 112-113)

**TheMealDB API (Free):**
- Purpose: Backup recipe data source when Firestore is empty; text search for recipes
- Base URL: `https://www.themealdb.com/api/json/v1/1` (`lib/services/firebase_service.dart` line 33)
- Endpoints used:
  - `/search.php?s={query}` - Text search (`searchRecipes()`, line 531)
  - `/lookup.php?i={id}` - Single recipe by ID (`getRecipe()`, line 510)
  - `/random.php` - Health check fallback (line 972)
- Auth: None (free public API, key `1` is the public test key)
- SDK/Client: `dio` with retry interceptor (exponential backoff, 3 max retries, 500ms base delay) (lines 56-70, 89-97)
- Data mapping: `_mealDbDetailToRecipe()` converts TheMealDB format to app `Recipe` model (lines 449-479)
